# 方块世界 (World Builder)

一个原生 macOS 交互式 3D 方块建造应用。可在地面或已有方块表面放置方块、右键删除、旋转和缩放视角，并将世界保存为 JSON 文件。

## 运行

需要 macOS 15 或更新版本及 Xcode 16 或更新版本。

运行 `sh build-app.sh` 生成 `dist/方块世界.app`，然后在 Finder 中打开。也可以在允许 Swift Package Manager 构建的环境运行 `swift run WorldBuilder`。

## 操作

- 在 3D 画面顶部点击“创造模式”或“漫游模式”切换，两种模式的当前按钮会高亮。
- 创造模式：左键点击地面或方块放置所选方块；右键点击方块清除；拖动旋转视角，滚轮缩放。
- 漫游模式：默认第一人称镜头，WASD 或方向键相对镜头方向行走；拖动鼠标或按 Q/E 转向。可切换“身后跟随”来看到小人。点击画面可恢复键盘焦点。此模式只探索，不编辑方块。
- 创造模式默认从建筑正面看，也可点击画面上方的“正面视角”恢复正面观察。
- 随时切回创造模式继续创作；新建、打开、保存和地图拼接位于左侧面板。

世界文件是可读的 `.json` 格式，包含名称与所有方块的坐标和材质。

启动时会自动载入 [三层小楼](Worlds/三层小楼.world.json) 示例世界。也可通过“打开世界…”载入其他文件。

## 拼接多个地图

1. 每个场景先用“保存世界…”存成 `.world.json` 文件。
2. 在当前地图左侧的“地图拼接”中选择东、西、南或北，点击“拼接地图…”，选取另一个世界文件。
3. 导入的方块会自动移动到当前地图相邻的一侧，保持原有高度和材质。保存当前地图即可得到合并后的世界。
4. 如果方向不合适，可在继续编辑前点击“撤销上次拼接”，换方向再试。

可用 [小庭院](Worlds/小庭院.world.json) 练习：在三层小楼中选择“南侧”，再拼接小庭院。两张地图接壤后，可按需清除墙体、铺设通道。
也提供了已拼好的 [三层小楼与庭院](Worlds/三层小楼与庭院.world.json)，可直接用“打开世界…”查看。
